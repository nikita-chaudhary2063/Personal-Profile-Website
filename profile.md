# Personal Profile Website

## 📌 About the Project

This is my first personal profile website created using HTML5 as part of my frontend development learning journey.

The website introduces me, provides information about my education, and includes useful links to external websites.

## 🚀 Features

- Personal introduction
- Education information
- Profile image with alternative text
- Google and GitHub links
- Back to Top navigation
- HTML comments for code organisation

## 🛠️ Technologies Used

- HTML5

## 📚 Concepts Learned

Through this project, I practised:

- HTML document structure
- Headings (`h1`, `h2`)
- Paragraphs (`p`)
- Line breaks (`br`)
- Hyperlinks (`a`)
- Images (`img`)
- HTML attributes (`href`, `src`, `alt`, `width`, `id`, `target`)
- Internal navigation using IDs
- HTML comments

## 📂 Project Structure

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
